# Ícones

Ícone do app: a cabeça do pato com chapéu num quadrado de cantos arredondados (22% do lado).

- `qac-icone-escuro` é o principal (fundo `#111111`, chapéu claro); `qac-icone-claro` para fundos escuros onde o ícone precisa destacar.
- `qac-favicon-32.png` é a versão simplificada para 16 e 32 px: sem faixa no chapéu e sem brilho no olho.
- `qac-icone-512.png` serve para `page_icon`, redes sociais e avatar.
